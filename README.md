# LabNote — 实验记录 + 日/周任务

Microsoft To Do 式的任务清单 + Obsidian 兼容、所见即所得的 Markdown 笔记。所有数据都是库文件夹里的普通 `.md` 文件。

## 运行

```bash
npm install          # 国内网络建议先设置 ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm run dev          # 开发模式
npm run build && npm start   # 构建后运行
npm run dist         # 打包 Windows 安装包 / 便携版到 release/（见下方说明）
npm test             # 单元测试（任务格式、Markdown 往返、Obsidian 导入）
```

本机打包时，electron-builder 默认缓存目录存在跨盘移动失败的问题，需先把缓存指到项目内（PowerShell）：

```powershell
$env:ELECTRON_BUILDER_CACHE="$PWD\.cache\electron-builder"; $env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"; npm run dist
```

产物：`release/LabNote Setup 0.1.0.exe`（安装版）、`release/LabNote 0.1.0.exe`（便携版，单文件免安装）。未做代码签名，首次运行 Windows SmartScreen 可能提示，选「仍要运行」。

## 功能

| 需求 | 实现 |
| --- | --- |
| 每日/每周任务、完成/未完成 | 「我的一天」「本周计划」「未完成汇总」；支持重要 ⭐、步骤、移到明天/本周、带入昨天未完成、一键复制周报 |
| 任务关联具体 md | 任务行点「＋📝」，在 `实验记录/` 下生成带「目标/方法/过程/结果/结论」模板的笔记，任务里写入 `[[链接]]`；笔记顶部可跳回任务 |
| 双链 | 单击选中、双击（或 Ctrl+单击）打开、右键复制/改文字/改目标；文件树或笔记顶部「复制链接」后可粘贴到任意笔记。复制粘贴笔记内容时双链、公式、待办都保持可用 |
| 任务备注 | 详情面板里可写备注（如实验取消原因），「标记为不做」一键完成并记录；保存为任务下缩进的 `> ` 行 |
| 按项目归类 | 文件树里拖动笔记到文件夹，或右键「移动到…」；重命名/移动会自动更新全库 `[[链接]]`（含任务里的关联） |
| 表格 | 钉钉式操作：鼠标悬停单元格时，列上方/行左侧出现手柄，点手柄选整列/整行并弹出菜单（插入、删除、对齐），点 ＋ 就地插入列/行，左上角 ⋯ 整表操作；右键单元格也有完整菜单；拖动列边线调宽度 |
| 富文本编辑（不用记语法） | 钉钉风格工具栏：标题、字号、颜色、高亮、表格（增删行列/对齐/合并）、引用、Callout、代码块、公式、双链；输入 `/` 唤出插入菜单；保存为标准 Markdown，随时切「源码模式」 |
| 目录 | 笔记右侧显示标题目录，点击跳转，滚动时高亮当前章节；笔记顶部「目录」按钮可隐藏/显示 |
| 图片 | 双击图片（或右键「查看原图」）全屏查看原图，滚轮缩放、拖动平移、双击切换 100%、Esc 关闭；粘贴/拖入自动保存为 `Pasted image 时间.png`，写成 `![[...]]`，附件目录遵循 `.obsidian/app.json`；右键图片「复制图片」，或选中内容 Ctrl+C / 「复制到钉钉」——图片会内嵌为 base64，直接粘贴到钉钉文档 |
| 无损迁移 Obsidian | 可直接打开现有 Obsidian 库原地使用；或「从 Obsidian 导入」整库逐字节复制 + SHA1 校验（含 `.obsidian`、附件等全部文件） |
| 多设备同步 | 库就是普通文件夹：放进 百度网盘同步空间 / 坚果云 / OneDrive / Syncthing 即可；手机端用 Obsidian App 打开同一个库 |

## 数据格式

```
库/
├─ 任务/每日/2026-10-26.md    - [ ] 跑 baseline ⏫ [[实验记录/2026-10-26 跑 baseline]]
├─ 任务/每周/2026-W44.md      （⏫ 重要，✅ 日期 = 完成日，兼容 Obsidian Tasks 插件）
├─ 实验记录/…                 从任务生成的实验笔记
└─ .labnote/settings.json     任务/笔记文件夹设置（设备本地配置不进库）
```

## 关于“无损”

- 只打开不编辑，文件不会被改写；外部（同步盘/Obsidian）修改会自动重新加载。
- 可视化编辑后保存，内容不丢，但部分**渲染效果相同的写法会被规范化**，例如：多余的 `\_` 转义、`|a|b|` → `| a | b |`、列表 4 空格缩进 → 2 空格、标题后补空行、连续空行合并。出现这种情况时笔记顶部会提示「保存时会规范化格式」，需要保留原样时请用源码模式编辑。
- 表格拖动调整过列宽后，会以 HTML 表格保存（Obsidian 能显示，但不能再按 Markdown 表格编辑）；点表格工具条上的「平均列宽」即恢复为 Markdown 表格。

## 同步建议

百度网盘同步空间可用，但冲突处理较弱：避免两台设备同时编辑同一篇笔记。任务按天分文件，冲突概率很低。若需要更可靠的冲突处理，推荐坚果云（WebDAV，Obsidian 手机端可配合 Remotely Save 插件）或 Syncthing（局域网 P2P，免费）。
